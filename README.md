

# ✦ Momentum Matrix

A personal productivity dashboard built around the Eisenhower Matrix. Organize tasks by urgency and importance, track completion, and focus on meaningful progress.

## Features

- **Do First:** Urgent and important tasks.
- **Schedule:** Important tasks that are not urgent.
- **Delegate:** Urgent tasks that are less important.
- **Reduce:** Tasks that are neither urgent nor important.
- Optional start and finish times.
- Optional task notes.
- Completion statistics and a daily progress bar.
- Browser-based task persistence using local storage.
- Responsive layout for desktop and mobile.
- Lightweight animations and a clean interface.

## Getting Started

### Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add tasks to any of the four quadrants.

No package installation or build step is required.

## Data and Privacy

Tasks are stored in the browser's local storage on the device and browser where the app is used. They are not automatically synchronized between devices or browsers. Clearing browser data may remove saved tasks, so export or back up important data before clearing it.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.

After GitHub Pages finishes deploying, the site should be available at:

https://ash25-chahare.github.io/momentum-matrix/
